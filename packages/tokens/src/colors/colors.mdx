# Colors

Raw color tokens exported by the `tokens` package. These are the source of
truth for every scale used across Polaris UI. Components should never
import these directly — themes are responsible for mapping them to CSS
variables.

Click any swatch below to copy its hex value.

## Solid values

`transparent` and `current` are omitted from the swatch grid below since
neither renders meaningfully as a static color:

- **`transparent`** (`transparent`) — has no visible fill by definition.
- **`current`** (`currentColor`) — resolves to the `color` of whichever
  element consumes it, so its rendered value depends entirely on context.
