# Opacity

Raw opacity scale exported by the `tokens` package.

Each swatch sits on a checkerboard backdrop rather than the docs card
background — against a solid background, low-opacity values (`0`, `5`,
`10`) would be visually indistinguishable from "no color at all", since
the swatch and background could end up rendering close to the same
apparent color depending on the active theme.
